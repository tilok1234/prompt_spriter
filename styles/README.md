# Styles

Validated, versioned style profiles live here.

The active production default is:

- [`assembler-inspired-v2`](assembler-inspired-v2/STYLE_GUIDE.md)

The original first-slice profile remains available for deliberate legacy work
and exact revision provenance:

- [`assembler-inspired-v1`](assembler-inspired-v1/STYLE_GUIDE.md)

Both are inspired by selected, read-only 8-bit Sprite Assembler references.
Category geometry and visual style remain separate contracts.

Promotion changes defaults only. It never relabels or redraws an existing
asset revision.
